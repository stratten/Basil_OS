# Support

Use the project’s public issue tracker for reproducible bugs, installation problems, and feature requests. Include the macOS version, Basil version or commit, Python version, and relevant redacted logs.

Do not use the public tracker for vulnerabilities, credentials, personal data, account tokens, or private recordings. Follow `SECURITY.md` for vulnerability reporting.

Basil Cloud is optional. Local-model and bring-your-own-key configurations do not require access to Basil Cloud, and community contributors do not need credentials for it.
