# Security policy

Do not disclose suspected vulnerabilities through the public issue tracker or a public pull request.

Before this staging tree is published, the maintainer must enable the repository host’s private vulnerability-reporting channel and replace this paragraph with its direct reporting link or a monitored security contact. Until that is done, this source tree is not ready for public release.

Reports should include the affected Basil version or commit, the impacted component, reproduction steps, expected and observed behavior, and any proof-of-concept needed to assess impact. Do not include third-party credentials or other sensitive data in a report.
